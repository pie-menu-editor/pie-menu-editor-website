Set up PME-F

Enter the purchase key shown on the page that brought you here. A PME account, password, or device registration is not required.

Verify your purchase

The key is checked against the purchase record.

The key is used to verify your purchase. It is not stored in Blender.

WIP: Preview only. Purchase verification is not connected yet.

What happens next

  1. Repository access is issued. You receive the Repository URL and access token.
  2. Add the Repository to Blender. Blender uses the opaque token to install and update PME-F.
  3. Save the recovery secret. Keep it somewhere safe outside Blender.

Keep the recovery secret outside Blender. You will need it if the Repository token must be replaced later.
