About PME-F

Pie Menu Editor Fork helps Blender users shape the interface around their own work. It continues the flexibility of the original add-on while focusing on current Blender compatibility and long-term maintenance.

  • Create pie menus and other custom UI without building an add-on from scratch.
  • Bring frequently used Blender actions into faster, personal workflows.
  • Use the actively developed 2.x line with Blender 5.0 and later.

Project history

PME-F is built for continuity: keeping established workflows usable while moving forward with Blender.

Pie Menu Editor was originally created by roaoao in 2016. PME-F began as a maintenance fork and now continues separately as the commercial 2.x line.

The completed 1.x maintenance line remains available as a public GPL archive for legacy users and source review.
